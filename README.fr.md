# Libre AI Capability Authorization

[English](README.md)

Les services ont besoin de permissions précisant quelle action est autorisée sur quelle ressource et sous quelles conditions. Ce projet explore l’autorisation par jetons Biscuit pour les développeurs de règles d’accès. Il se concentre sur des permissions délimitées et leur délégation, afin de transmettre des droits réduits pour une tâche particulière.

## Usages visés

- Limiter une permission de service à une action et une ressource précises.
- Restreindre davantage un jeton délégué pour un destinataire ou un usage particulier.
- Contrôler l’expiration, la révocation et le périmètre d’organisation selon des règles explicites.
